OpenTelemetry-native agent evaluation

Score agent behavior from traces you already have.

agentevals evaluates AI agent sessions from OpenTelemetry traces, so you can measure quality, compare runs, and catch regressions without re-running the agent.

Get started View on GitHub 
$ pip install agentevals-cli
$ agentevals run --otlp-endpoint http://localhost:6006/v1/traces --model openai/gpt-4o-mini
→ scored 128 traces
→ exported results
